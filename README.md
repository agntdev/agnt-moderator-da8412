# agnt Moderator

Telegram group moderation bot that greets and verifies new members, enforces anti-spam rules, provides admin commands, and maintains a short action log and basic metrics.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
